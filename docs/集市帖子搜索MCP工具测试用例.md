> **测试前提**：确保已配置小秋 API Token（设置 → 集市帖子搜索），GLM API Key 已配置，模型全部加载完成（状态栏四个指示灯常亮）。

## 二、API 连通性测试

### TC-2.1 正向连接测试（设置面板）

**操作**：
1. 打开设置面板
2. 在"集市帖子搜索（小秋）"区域填写正确的 API Token
3. 保持 API 地址为 `https://ssemarket.cn`（默认值）
4. 点击「测试连接」按钮

**预期结果**：
- 弹出绿色提示："小秋集市搜索连接成功"
- 按钮短暂显示加载状态后恢复

**验证点**：`success: true`

---

### TC-2.2 未配置 Token 时测试连接

**操作**：
1. 清空 API Token 输入框
2. 点击「测试连接」

**预期结果**：
- 弹出红色提示："未配置 API Token，请在设置中填写小秋 API Token"

**验证点**：`success: false`，错误信息明确

---

### TC-2.3 错误 Token 测试

**操作**：
1. 填入一个明显错误的 Token（如 `invalid-token-12345`）
2. 点击「测试连接」

**预期结果**：
- 弹出红色提示："连接失败：…"（具体内容取决于服务端返回）

**验证点**：`success: false`，不崩溃

---

### TC-2.4 错误 API 地址测试

**操作**：
1. 将 API 地址改为 `https://example.com`
2. 点击「测试连接」

**预期结果**：
- 弹出红色提示，提示包含"无法连接"或"测试失败"

**验证点**：`success: false`，超时/连接错误被正确捕获

---

### TC-2.5 未配置 Token 时直接搜索

**操作**：
1. 确保小秋 API Token 为空
2. 对副官说："搜帖子 AI"

**预期结果**：
- 副官回复："指挥官，集市搜索需要配置小秋 API Token，请在设置中填写后再试。"

**验证点**：不崩溃，错误提示友好

---

## 三、结果展示测试（格式保留）

> **前提**：小秋 API Token 已正确配置，服务端正常响应。

### TC-3.1 基本结果展示

**操作**：
1. 对副官说："搜帖子 保研"

**预期结果**：
1. 前端聊天区出现副官回复
2. 回复以 **"【帝国情报部·集市检索结果】"** 开头
3. 称呼用户为"指挥官"
4. 风格为军旅干练风，带冷幽默

**验证点**：
- 结果以 `【帝国情报部·集市检索结果】` 开头
- 回复含"指挥官"称呼

---

### TC-3.2 链接保留测试

**操作**：
1. 对副官说："搜帖子 实习"

**预期结果**：
1. 回复中所有帖子标题以 Markdown 链接格式呈现：`[标题](URL)`
2. 每个链接完整可点击（前端渲染为可点击链接）
3. 不丢失任何一条原始结果中的帖子

**验证点**：
- 每个帖子都有 `[标题](URL)` 格式的链接
- 对比后端日志 `[MCP-ForumSearch] API 返回长度: XXXX 字符`，润色后的结果帖子数量一致

---

### TC-3.3 分类结构保留测试

**操作**：
1. 说一个会返回多分类结果的查询（根据小秋实际索引的数据确定，如"搜帖子 经验"）

**预期结果**：
1. 回复中保留原文的分类/分组结构（如"经验分享类""求助讨论类"等）
2. 每个分类下的帖子完整列出

**验证点**：
- 润色结果中的分类标题与原文一一对应
- 没有帖子被归类到错误的分类下

---

### TC-3.4 总结段落保留测试

**操作**：
1. 说一个可能触发小秋返回总结段的查询（如"论坛最近有什么新帖子"）

**预期结果**：
1. 如果原文末尾有总结段落，润色后用自己的话重新组织
2. 不丢失总结中的关键信息
3. 不编造原文中没有的信息

**验证点**：
- 有总结段落时信息完整
- 无总结段落时不会出现凭空编造的内容

---

### TC-3.5 GLM 润色降级测试

> **模拟方法**：暂时清空 GLM API Key，使 GLM 不可用。

**操作**：
1. 清空 GLM API Key
2. 对副官说："搜帖子 AI"

**预期结果**：
1. 后端日志显示 `[MCP-ForumSearch] GLM 润色失败: ...`
2. 前端仍能展示搜索结果
3. 结果为原文加上前缀：`【帝国情报部·集市检索结果】\n\n{原文}`
4. 仍保留所有帖子的标题和链接

**验证点**：
- 不会因为 GLM 不可用而完全丢失结果
- 原文中的所有链接完整保留

## 五、设置持久化测试

### TC-5.1 Token 存储与同步

**操作**：
1. 在设置面板填入小秋 API Token 和 API 地址
2. 刷新页面（F5 或重启应用）
3. 重新打开设置面板

**预期结果**：
- Token 和地址仍然存在（从 localStorage 加载）
- 后端也能获取到正确的凭据

**验证点**：
- `localStorage.adjutant_settings` 中包含 `forumSearchApiToken` 和 `forumSearchBaseUrl`
- 后端接收到的 `update_settings` 消息包含这两个字段

---

### TC-5.2 API 地址默认值

**操作**：
1. 首次安装应用 / 清除 localStorage 后打开设置

**预期结果**：
- API 地址输入框默认显示 `https://ssemarket.cn`
- Token 输入框为空

**验证点**：默认值正确
