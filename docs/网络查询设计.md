# 阿塔尼斯 AI 语音助手 - 网络查询系统设计文档
**版本**：v2.2  
**适用架构**：统一 MCP 工具链架构  
**设计原则**：本地零智能、记忆完全隔离、状态机复用、最小改动  
**最后更新**：2026年5月23日

## 1. 系统概述
网络查询系统是泰伦帝国副官 AI 的 MCP 工具链模块之一，为本地 Qwen2.5-3B 模型补充实时信息获取能力。本系统严格遵循现有 MCP 架构设计规范，所有智能逻辑完全由云端 GLM-4-Flash 完成，本地仅执行 API 调用等原子操作，本地 LLM 全程无感知。

## 2. 核心设计原则
完全继承统一 MCP 架构的核心原则：
1. **本地零智能**：所有意图判断、查询重写、结果处理、回复生成 100% 由 GLM-4-Flash 完成
2. **记忆完全隔离**：网络查询相关对话不写入短期记忆、不送入长期记忆提取队列
3. **状态机复用**：完全复用 `transcribe_substate = "generating"` 状态及现有锁、取消事件机制
4. **统一错误处理**：所有异常返回标准化副官风格提示
5. **可插拔扩展**：无需修改核心架构，仅需添加关键词和处理函数即可集成

## 3. 技术选型
| 组件 | 技术选型 | 核心优势 |
|------|----------|----------|
| 搜索引擎 | 百度 AI 搜索（千帆平台） | 国内直连、永久免费额度（100次/天）、百度原生结果、OpenAI SDK 兼容 |
| 智能处理 | 智谱 GLM-4-Flash | 响应速度快、成本极低、中文理解能力强 |
| 通信协议 | 复用现有前后端 WebSocket 协议 | 无需新增接口 |
| 状态管理 | 复用现有全局状态机 | 无需新增状态定义 |

## 4. 完整处理流程
```
用户输入（如"查询2026年星际争霸2最新赛事"）
    ↓
【MCP 统一入口】本地关键词预过滤（命中 web_search 关键词）
    ↓
【MCP 任务分发器】路由至 web_search_handler
    ↓
步骤1：GLM-4-Flash 生成优化后的搜索关键词
    ↓
步骤2：调用百度 AI 搜索 API 获取前3条原始结果
    ↓
步骤3：GLM-4-Flash 完成信息提取、去重、摘要、副官风格生成
    ↓
【统一输出】推送 chat_complete 事件 + TTS 播报
    ↓
状态机自动切换回 idle 状态
```

## 5. MCP 集成规范
### 5.1 关键词配置
在 `keyword_filter.py` 的 `MCP_KEYWORDS` 字典中添加以下配置：
```python
MCP_KEYWORDS = {
    # 原有 todo/weather/system_status/time_tool 保留
    "web_search": [
        "查询", "查找", "搜索", "检索", 
        "查一下", "找一下", "帮我查", "帮我找"
    ]
}
```

### 5.2 任务分发器映射
在 `mcp_dispatcher.py` 中添加工具映射：
```python
MCP_HANDLERS = {
    "todo": todo_handler,
    "weather": weather_handler,
    "system_status": system_status_handler,
    "time_tool": time_tool_handler,
    "web_search": web_search_handler  # 新增
}
```

### 5.3 状态机复用
- 执行网络查询时，自动进入 `transcribe_substate = "generating"` 状态
- 支持通过 `cancel_generation` 指令取消查询
- 复用现有 `generation_lock` 和 `cancel_generation_event`
- 查询完成后自动切换回 `idle` 状态

### 5.4 通信协议
**完全复用现有协议**，无需新增任何指令或事件：
- 前端 → 后端：复用 `send_message` 指令
- 后端 → 前端：复用 `chat_complete`、`chat_cancelled`、`error` 事件

## 6. 核心代码实现
### 6.1 依赖安装
```bash
pip install openai>=1.0.0
```

### 6.2 完整实现代码
```python
# backend/mcp/web_search.py
from openai import OpenAI
from typing import Optional

# 初始化客户端（复用项目全局配置）
glm_client = OpenAI(
    api_key="YOUR_GLM_API_KEY",
    base_url="https://open.bigmodel.cn/api/paas/v4/"
)

baidu_search_client = OpenAI(
    api_key="YOUR_BAIDU_QIANFAN_API_KEY",
    base_url="https://qianfan.baidubce.com/v2/ai_search"
)

def web_search_handler(user_input: str) -> str:
    """
    网络查询工具处理函数
    遵循MCP本地零智能原则，所有逻辑由云端GLM完成
    """
    try:
        # 步骤1：查询重写 - 生成最适合搜索引擎的关键词
        rewrite_prompt = f"""你是一个专业的搜索引擎查询优化器。
请将用户的自然语言问题转化为1个最适合搜索引擎的精准关键词。
要求：
1. 只输出关键词，不要添加任何其他内容
2. 保留核心信息，去除口语化表达
3. 优先使用中文关键词
4. 如果是时效性问题，添加"2026"年份

用户问题：{user_input}
优化后的关键词："""
        
        rewrite_response = glm_client.chat.completions.create(
            model="glm-4-flash",
            messages=[{"role": "user", "content": rewrite_prompt}],
            temperature=0.1,
            max_tokens=50,
            timeout=10
        )
        search_keyword = rewrite_response.choices[0].message.content.strip()
        
        # 步骤2：调用百度AI搜索获取原始结果
        search_response = baidu_search_client.chat.completions.create(
            model="deepseek-r1",  # 百度AI搜索固定模型名
            messages=[{"role": "user", "content": search_keyword}],
            max_tokens=1000,
            stream=False,
            timeout=15
        )
        raw_results = search_response.choices[0].message.content
        
        # 步骤3：结果处理与副官风格生成
        final_prompt = f"""你是泰伦帝国情报部的信息分析官。
请严格按照以下要求处理搜索结果：
1.  从以下搜索结果中提取与用户问题相关的核心信息
2.  去除广告、无关内容和重复信息
3.  生成简洁明了的结构化摘要，每条信息不超过50字
4.  如果没有找到相关信息，请明确说明"未检索到相关情报"
5.  不要添加任何你自己的知识，只使用搜索结果中的信息
6.  回复开头必须是：【帝国情报部检索结果】
7.  回复结尾必须是：以上情报来自星际网络公开渠道，仅供参考。

用户问题：{user_input}

搜索结果：
{raw_results}

副官回复："""
        
        final_response = glm_client.chat.completions.create(
            model="glm-4-flash",
            messages=[{"role": "user", "content": final_prompt}],
            temperature=0.1,
            max_tokens=500,
            timeout=10
        )
        
        return final_response.choices[0].message.content.strip()
    
    except Exception as e:
        return f"指挥官，星际网络接入失败：{str(e)}"
```

## 7. 异常处理
所有异常统一返回副官风格提示，保持与其他 MCP 模块一致：

| 异常场景 | 错误提示 |
|----------|----------|
| GLM API 调用失败 | "指挥官，情报分析系统暂时不可用，请稍后再试。" |
| 百度 AI 搜索 API 调用失败 | "指挥官，星际网络连接中断，请检查网络连接。" |
| 搜索结果为空 | "指挥官，未检索到相关情报。" |
| 用户取消查询 | "指挥官，情报检索已终止。" |
| 超时错误 | "指挥官，情报检索超时，请稍后再试。" |

## 8. 部署与配置
### 8.1 API Key 获取
1. **智谱 GLM-4-Flash**：访问 [智谱开放平台](https://open.bigmodel.cn/) 注册获取
2. **百度 AI 搜索**：
   - 访问 [百度智能云千帆平台](https://console.bce.baidu.com/qianfan/)
   - 完成实名认证
   - 开通 "AI 搜索" 服务
   - 获取 API Key 和 Secret Key

### 8.2 安全配置
- API Key 禁止硬编码在代码中，使用环境变量或配置文件存储
- 打包时使用 Electron `safe-storage` 加密存储敏感信息
- 配置 API 调用频率限制，避免超出免费额度

### 8.3 打包注意事项
- 无需额外打包任何模型文件
- 确保 `openai` 库包含在后端依赖中
- 网络权限：允许应用访问 `open.bigmodel.cn` 和 `qianfan.baidubce.com`

## 9. 备选方案
如果百度 AI 搜索不符合需求，可替换为 **SerpAPI（百度引擎）**：
- 免费额度：每月100次
- 国内可访问
- 代码修改量极小，仅需替换搜索部分逻辑

SerpAPI 搜索代码示例：
```python
import serpapi

def serpapi_search(keyword: str) -> list:
    client = serpapi.Client(api_key="YOUR_SERPAPI_KEY")
    params = {
        "engine": "baidu",
        "q": keyword,
        "hl": "zh-CN",
        "gl": "cn",
        "num": 3
    }
    result = client.search(params)
    return [{"title": item["title"], "snippet": item["snippet"]} 
            for item in result.get("organic_results", [])]
```
