hermas agent记忆架构
应用在后台时，可以尝试整合成中期记忆

①星际风格视觉 / 音效体系
核心功能：
界面主题：默认泰伦帝国红黑配色 + 休伯利安号舰桥背景，加载动画为帝国标志旋转，按钮 / 边框带「军工机械质感」；
交互音效：唤醒成功播放《星际争霸 2》副官提示音、发送消息播放帝国指令音、TTS 播报开始 / 结束播放短音效。
实现思路：
Vue 前端加主题样式文件（scss 变量控制配色 / 背景），Electron 加载本地音效文件（webContents.send触发播放）；
模型加载 / 状态切换时，替换原有文字提示为「唤醒模块校准完成（帝国制式）」等星际风格文案。

②全局快捷键体系，包含：打开/关闭窗口、录音、暂停生成、暂停播报

③悬浮窗模式：窗口缩小为星际风格悬浮球（类比360加速球），可拖拽，点击展开完整窗口，支持置顶（无论电脑打开什么内容，一直显示在页面最上层）和自动隐藏（靠近板边自动隐藏）

④趣味彩蛋
星际争霸彩蛋指令
核心功能：语音 / 文字触发专属彩蛋，比如：
「副官，来一句蒙斯克的演讲」→ AI 回复星际争霸经典台词 + TTS 用激昂音色播报；
「报告当前战况」→ 随机返回泰伦帝国风格的趣味战况（「休伯利安号巡航中，暂无异虫入侵」）；
「启动大和炮」→ 播放星际争霸大和炮音效 + TTS 播报「大和炮充能完毕，准备开火！」。
实现思路：
后端维护彩蛋指令映射表（关键词→回复文本 + 音效文件 + TTS 音色），匹配到关键词时触发对应逻辑；
前端加「彩蛋列表」弹窗，展示所有可触发的彩蛋指令。
2. 成就系统
核心功能：记录使用行为并解锁星际风格成就，比如：
「初出茅庐」：首次唤醒副官；
「帝国传令官」：累计发送 100 条消息；
「离线战神」：纯离线模式使用 24 小时；
前端展示成就徽章（星际风格图标），解锁时 TTS 播报成就提示。
实现思路：
后端新增achievements.json记录成就进度，每次触发行为时更新进度；
前端加成就面板，实时展示已解锁 / 未解锁成就

⑤TTS 音频缓存
核心功能：初次播报文本时直接缓存到本地，关闭应用后清除cache，重复播报同一文本时，直接播放本地缓存的音频文件（无需重新合成），提升播报响应速度。
实现思路：
后端对 TTS 文本做 MD5 哈希，以哈希值为文件名缓存音频文件到backend/cache/；
合成前先检查缓存，存在则直接播放，不存在则合成 + 缓存。

⑥MCP功能：语音指令控制本地文件
核心功能：
语音指令控制本地文件：「副官，打开 D 盘的项目文档」「副官，新建一个名为测试的 txt 文件」「副官，关闭当前文件夹」；
系统状态查询：「副官，查看当前 CPU 占用」「副官，告诉我剩余内存」「副官，检查磁盘空间」。
实现思路：
后端 Python 通过os/subprocess/psutil库实现文件操作 / 系统监控，前端将语音转写文本解析为指令（关键词匹配：打开 / 新建 / 关闭 + 路径 / 文件名）；
新增前端「文件指令调试」面板，可视化展示指令执行结果 / 错误。

⑦定时提醒
语音定时提醒：「副官，30 分钟后提醒我写代码」「副官，每天 18 点提醒我下班」，到点自动 TTS 播报。
副官接入电脑时间，可以感知到当前时间段

⑧天气预报
调用天气API，当用户有需求时可以给出正确回复
