# 时间感知测试用例集

## 使用说明

以下测试用例用自然语言说出，验证 TODO 功能是否正确解析截止日期。

**如何测试**：对副官说出左侧的句子，查看创建的待办事项的 `due_date` 是否与预期日期匹配。

**基准日期**：测试当天。预期结果中的相对偏移（如 "+2天"）从今天起算。

---

## 1. 基础相对天数

| # | 说出的话 | 预期 due_date | 说明 |
|---|---------|--------------|------|
| 1.1 | "提醒我明天下午三点开会" | 明天 15:00 | 明天+下午时间 |
| 1.2 | "明天要交报告别忘了" | 明天 09:00 | 明天+默认上午 |
| 1.3 | "后天上午十点去体检提醒我" | 后天 10:00 | 后天+上午时间 |
| 1.4 | "大后天有一个聚餐帮我记一下" | 三天后 09:00 | 大后天=+3天 |
| 1.5 | "明天跨月" | 明天 09:00 | 测试月底跨月 |
