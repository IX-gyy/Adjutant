对于用户的一条对话，我们的应用是如何判断它到底是：①本地模型生成回复的对话②触发MCP路径的对话③需要添加TODO的对话④触发彩蛋的对话

## 应用意图分类流程

你的应用通过**多层过滤器**按顺序判断用户输入属于哪种类型。整个流程如下：

### 判断顺序和逻辑

```
1. 首先检查 → 彩蛋匹配
   ↓ 不满足则进入下一步
2. 然后检查 → MCP 工具调用
   ↓ 不满足则进入下一步  
3. 然后检查 → 复杂问题（切换云端GLM）
   ↓ 不满足则进入下一步
4. 最后 → 本地模型生成回复
```

---

### ① 彩蛋匹配（优先级最高）

**触发条件**：
- 彩蛋开关开启（`easter_egg_enabled = True`）
- 用户输入以"副官"或"副官，"开头

**匹配方式**（按优先级）：
1. **精准指令匹配**：100%完全匹配触发指令（如"副官，帝国征兵令"）
2. **场景关键词匹配**：同时命中核心关键词+辅助关键词
3. **简化关键词匹配**：命中任意核心关键词
